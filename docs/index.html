Max for Live device

Producer for Live

A Max for Live MIDI Effect that sits inside Ableton, reads your session, and generates drum, melody and chord patterns into the highlighted clip without leaving Live.

  • Reads BPM, key, track and devices
  • Generates 1, 2, 4, 8 or 16 bar clips
  • Bring your own Anthropic API key

Quick start

Install in two commands.

Paste these into Claude Code, on the web or in the CLI.

Claude Code
> /plugin marketplace add patrickking67/producer
> /plugin install producer@producer

The 6 cloud MCPs (Splice, Spotify, Google Drive, Gmail, Google Calendar, Canva) sign in on first use. The Ableton MCP runs locally: install it separately, see CONNECTORS.md.

Slash commands

12 slash commands.

Each maps to a skill that also triggers from plain language. Describe what you want.

/review

Peer-level teardown of a track, loop, or arrangement.

/brainstorm

3-5 distinct creative directions, each with a reference.

/midi

Chord progressions, basslines, drum patterns and melodies as .mid.

/sound

Patch recipes for stock Ableton devices, with a Splice fallback.

/mix

Mix and master moves: LUFS, sidechain, low-end glue, references.

/docs

Surgical lookups in the Live, Push, Move and Note manuals and the knowledge base.

/library

Browse your User Library and Packs like Live's left-hand browser.

/arrange

Bar-by-bar arrangement coach: energy curve and section moves.

/reference

Build a Spotify reference playlist with BPM, key and loudness notes.

/stems

Prep stems for mastering, remix, sync, DJ tools and live.

/release

Master target, metadata, artwork, ISRC and release-day schedule.

/session

Drive Live directly: create tracks, load presets, fire clips.

Agent

ableton-engineer

End-to-end multi-step tasks, such as a tech house starter set, a release prep across streaming and Beatport, or a comparison against five references with the mix moves written out. It reads session state, calls the right skills in order, files artifacts and returns a short status.

Read four complete workflows
Quick taste
> /brainstorm I'm stuck on the second drop of my tech house track in F minor at 126
> /midi 4-bar tech house bassline in F minor, 126 bpm, dark, swung
> /sound make me a Drum Rack kick: punchy 60 Hz
> /arrange draft the full 6-minute arrangement for the loop I just imported
> /mix my drop dies in the car
> /release prep this for a Beatport release on July 25
> /session set BPM to 126, create 4 MIDI tracks, load my favourite drum rack

Add them in the Claude app

The plugin itself runs in Claude Code. The connectors can also be added directly in Claude on the web or desktop.

  1. Open Claude and go to Settings, Connectors.
  2. Choose Add custom connector, or pick one from the directory where it is listed.
  3. Paste the connector URL above and sign in.
  4. In Claude Desktop, install the Ableton Knowledge extension separately under Settings, Extensions.

Codex CLI

Same connectors, in Codex.

Codex has no plugin marketplace but it speaks MCP. Paste this block into ~/.codex/config.toml to get the same 6 remote connectors. Local Ableton control is configured separately. The slash commands and skills are specific to Claude Code, so in Codex describe what you want.

~/.codex/config.toml
# Remote connectors: sign in on first use
[mcp_servers.splice]
url = "https://mcp.splice.com/mcp"

[mcp_servers.spotify]
url = "https://mcp-gateway-external-pilot.spotify.net/mcp"

[mcp_servers.google_drive]
url = "https://drivemcp.googleapis.com/mcp/v1"

[mcp_servers.gmail]
url = "https://gmailmcp.googleapis.com/mcp/v1"

[mcp_servers.google_calendar]
url = "https://calendarmcp.googleapis.com/mcp/v1"

[mcp_servers.canva]
url = "https://mcp.canva.com/mcp"

Or run codex mcp add --url <url> <name> for each one. Needs a Codex CLI with streamable HTTP MCP support. Full file: plugins/producer/codex-config.toml.
