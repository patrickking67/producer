Producer

Privacy

Last updated 2026-11-23.

What Producer collects

Nothing. The Producer plugin is Markdown instructions, JSON manifests and connector settings. It has no server, no analytics and no telemetry, and the author receives no data from it.

The Claude Code plugin

Skills and commands run inside your own Claude Code session, so your prompts and any files you share are handled under the terms of the Claude product you use. The plugin declares six remote connectors (Splice, Spotify, Google Drive, Gmail, Google Calendar and Canva). Each one asks you to sign in with its provider the first time you use it. Producer never sees your credentials, and each provider handles your data under its own privacy policy. You can remove any connector at any time.

The Max for Live device

The device sends your request and basic session context (tempo, key, track name, track type, device names and clip length) to the Anthropic API at api.anthropic.com. It uses the API key you type in, which is held in memory while the device is loaded and is not written to disk by the scripts. No other server is contacted.

The site

This site is static and hosted on GitHub Pages. It sets no cookies and loads no analytics. GitHub may log requests under its own policy.
